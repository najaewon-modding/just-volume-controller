# Volume Desk

마인크래프트에서 개별 사운드의 음량을 원하는 만큼 줄일 수 있는 NeoForge 클라이언트 모드입니다.

## 주요 기능

- 현재 클라이언트에 로드된 모든 사운드 이벤트를 자동으로 불러옵니다.
- 사운드를 네임스페이스와 ID 경로에 따라 트리 구조로 정리합니다.
- 각 사운드의 음량을 0%부터 100%까지 숫자로 설정할 수 있습니다.
- 100%는 원래 음량, 0%는 음소거를 의미합니다.
- 바닐라뿐 아니라 설치된 모드와 적용된 리소스 팩의 사운드도 함께 표시합니다.
- 모든 설정은 클라이언트에만 적용되므로 서버에 모드를 설치할 필요가 없습니다.

## 지원 환경

| 항목 | 버전 |
| --- | --- |
| Minecraft | 26.1.2 |
| NeoForge | 26.1.2.97 |
| 실행 환경 | 클라이언트 |

## 사용 방법

1. 메인 메뉴 또는 게임 메뉴에서 `Mods`를 엽니다.
2. 모드 목록에서 `Volume Desk`를 선택합니다.
3. `Config` 버튼을 누릅니다.
4. 트리를 펼쳐 조절할 사운드를 찾습니다.
5. 0부터 100 사이의 음량 값을 입력합니다.
6. 설정 화면을 닫으면 변경한 값이 저장됩니다.

## 사운드 분류

사운드는 전체 ID를 기준으로 다음과 같은 트리에 배치됩니다.

- `minecraft`
    - `entity`
        - `villager`
            - `ambient`
            - `hurt`
            - `death`
    - `block`
    - `item`
    - `music`
    - `ui`

예를 들어 주민의 평상시 소리는 `minecraft:entity.villager.ambient`, 피해 소리는 `minecraft:entity.villager.hurt`로 서로 독립적으로 조절할 수 있습니다.

## 음량 설정

| 값 | 의미 |
| ---: | --- |
| 100% | 원래 음량 |
| 1%–99% | 원래보다 작은 음량 |
| 0% | 음소거 |

100%인 사운드는 별도 설정으로 저장하지 않으며, 사용자가 변경한 값만 설정 파일에 기록합니다.

설정은 게임 디렉터리의 `config/njw_volume_desk.json`에 저장됩니다.

## 모드의 범위

Volume Desk는 기존 사운드의 음량을 줄이는 데만 사용됩니다. 새로운 사운드를 추가하거나 기존 사운드 파일을 교체하지 않으며, 100%를 초과하는 증폭 기능은 제공하지 않습니다.

## 개발 상태

현재 초기 개발 단계입니다. 구현 과정에서 화면 구성과 설정 파일 형식은 변경될 수 있습니다.
